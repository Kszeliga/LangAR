# 🚀 LangAR – AI-Powered AR Language Learning

> Learn languages by talking to an AI character in Augmented Reality.

LangAR is a mobile application that combines **Artificial Intelligence**, **Augmented Reality**, and **voice interaction** to create an immersive language learning experience.

Instead of traditional methods, users interact with a **3D anime character** that listens, understands, and responds in real time.

## 🧠 Core Concept

LangAR transforms language learning into **real conversation**:

- 🎯 Speak instead of typing  
- 🤖 Talk with AI instead of memorizing  
- 🌍 Learn in real-world context using AR  

---

## ⚡ Key Features

### 🎥 Augmented Reality
- ARCore integration
- Character placed in real environment
- Camera-based interaction

### 🤖 AI Conversation
- OpenAI-powered responses
- Context-aware dialogue
- Natural conversations

### 🎤 Voice Interaction
- Speech-to-Text (STT)
- Text-to-Speech (TTS)
- Real-time communication

### 🧑‍🎤 3D Character
- Anime-style model
- Interactive presence
- Ready for lip-sync system

### ☁️ Backend
- Firebase Functions
- Secure API handling
- Scalable architecture

## 🏗️ System Architecture

User → Speech-to-Text → Firebase → OpenAI API → Response → Text-to-Speech → AR Character

## ⚙️ Setup Instructions

### 1. Clone repository
git clone https://github.com/Kszeliga/LangAR.git

cd LangAR

### 2. Open in Unity
Use **Unity 2022.3 LTS**

### 3. Firebase Setup
- Add `google-services.json`
- Enable Authentication
- Deploy backend:

firebase deploy

### 4. OpenAI Setup
- Add API key to Firebase Secrets
- Connect endpoint with Unity

### 5. Run the app
- Use Android device with ARCore
